# Bibliography

The sources of the methods, benchmarks, statistics, and figures DispatchAtlas
implements, generated from the bibliography of the package when this site is
built. Each entry lists the solvers, benchmark families, suites, figures, and
statistical methods that cite it.

Export entries as BibTeX to cite what you use:

```bash
dispatchatlas references --solver tabu-search --family job-shop --format bibtex
dispatchatlas references kolisch1996serial --format bibtex
```
