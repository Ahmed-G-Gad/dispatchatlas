# Tuning

Automatic configuration of a solver's parameters by iterated racing: parameter spaces, the racing of configurations with the Friedman test and Conover's comparisons, and elitist iterated racing with a budget of runs. The package never starts a solver; the caller supplies the function that runs the experiments.
